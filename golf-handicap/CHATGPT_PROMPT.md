# ChatGPTへの頼み方

ChatGPTに、次のファイルを添付してから下の文章を貼り付けてください。

- `SPEC.md`(仕様書。必須)
- `handicap.js`(計算の元コード。計算結果を完全に合わせたいとき)
- `examples/worked-example.json`(答え合わせ用のデータ)
- `hirihiri-handicap.html`(元のアプリ。見た目や操作の参考)

---

## 貼り付ける文章

```
ゴルフ仲間うちのコンペで使うハンデ計算Webアプリを作ってください。
添付の SPEC.md が仕様書です。画面・データ・計算式・検証用の数値がすべて書いてあります。

必ず守ってほしいこと:
1. ハンデの計算は SPEC.md 第5章の式どおりにしてください。添付の handicap.js が元の実装なので、迷ったらそちらに合わせてください。
   - 実力推定は「古いラウンドから1回ずつ」更新し、カットはその時点の推定から ±8打で行う。
   - 優勝確率の微調整(モンテカルロ4000回)は省略しない。乱数はシードを固定する。
2. 作ったら SPEC.md 第6章の計算例で答え合わせをしてください。
   微調整オフの6ラウンド目のハンデは A 0 / B 8.5 / C 14.5 / D 23 と完全に一致すること。
3. SPEC.md 第7章のシミュレーションを実行して、7.4 の合格ラインを満たすことを確認し、結果の表を見せてください。
4. SPEC.md 第8章のテストを書いて、全部通ることを確認してください。
5. 1つのHTMLファイルで動くようにしてください(スマホのブラウザで開くだけで使える。データは localStorage に保存)。
   書き出し/読み込みの形式は SPEC.md 第4章のJSONにして、examples/worked-example.json をそのまま読み込めるようにしてください。

最後に、完成したHTMLファイルをダウンロードできる形で渡してください。
```

---

## うまくいかないときの追加の頼み方

- 計算例と数字が合わない → 「SPEC.md 6.2 の途中経過と、あなたの実装の途中経過を1ラウンドずつ並べて、どこでずれたか調べて直してください」
- 優勝確率が偏る → 「微調整のステップ(SPEC.md 5.6)が実装されているか、40回くり返しているか確認してください」
- 前回ビリばかり勝つ → 「実力推定で直近のラウンドだけを使っていないか、カット(±8打)が入っているか確認してください」
